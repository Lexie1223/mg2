1. One issue I encountered was that I sometimes forgot to add `f` after decimal numbers, like `1.0f` or `0.5f`, when writing the else if statements. This caused errors in my code. After checking the errors, I realized that I needed to add `f` because the variable `r` is a float. I fixed the problem by adding `f` after the numbers.
